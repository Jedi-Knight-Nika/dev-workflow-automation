## Deliberately gated

No paid benchmark tickets, model escalation, price replacement, database reset or
automatic merge-policy changes are part of deploying observability. A real Linux
host benchmark, provider-native resume/compaction acceptance, backup restoration,
and 10–20 authorized representative tickets remain acceptance gates. ML and
resource-aware admission stay deferred as specified until enough data is measured.

## Metric contract

PostgreSQL AI receipts are cost truth; Prometheus is operational/resource truth.
Unknown cost and missing resource samples are null, not zero. Historical resource
measurements cannot be reconstructed before collection began. UTC bounds apply to
all queries. CPU percentages for containers mean 100% = one logical core. Host CPU
percentage is normalized across all host cores. Availability counts successful
blackbox samples / valid samples, with coverage reported separately. Scrape health
is not user-facing uptime. Forecasts use only earlier completed tasks and never
alter execution admission. Original forecast estimates are immutable.
